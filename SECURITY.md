# Security policy

Security fixes target the current `main` branch and the latest tagged release when releases exist. Older versions do not receive backports.

Report vulnerabilities using [private vulnerability reporting](https://github.com/psiotwo/dl-tab/security/advisories/new) when enabled. If that option is unavailable, open an issue requesting a private reporting channel without including vulnerability details, credentials, or exploit code.

Automated dependency and CodeQL checks help identify known issues; they do not replace code review. See [Contributing](CONTRIBUTING.md) for the checks and the GitHub settings needed to enforce them.
